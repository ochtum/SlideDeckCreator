# LTスライド視覚レビュー基準

## 合格条件

- 全スライドが1280x720相当の16:9表示で崩れていない。
- 各ページのアニメーション完了後、読むべきテキスト・カード・図版・結論帯が重なっていない。
- テキストがカードやゾーンからはみ出していない。
- テキストに見切れがない
- スライド外にはみ出す要素がない。
- 読ませる要素が上下左右の端に寄りすぎていない。
- 画像が壊れていない。
- 発表者ビューの現在プレビューが投影側の現在スライドDOMと一致している。
- 発表者ビューの次プレビュー、ノート、タイマー、操作ボタン、ショートカット一覧が見切れず表示されている。

## 余白の考え方

標準の内側余白は40pxを目安にする。LTスライドでは可読テキストはより内側、特に上端は広めに取る。ブランドバッジ、ページ番号、フッター、背景装飾は例外としてよい。

## 重なりの考え方

検査は `.zone[data-zone]` を主対象にする。親子要素の自然な包含や、明示的に `data-overlap-ok` を付けた図解の重なりは問題にしない。本文カード、図版、結論帯、QR、タイトルゾーンが互いにぶつかる場合は修正対象にする。

## レビュー時の優先順位

1. 内容が読めない、文字が欠ける、ページ外へ消える問題
2. 要素同士の重なりで意味が壊れる問題
3. 発表者ビューと投影側で現在スライドの見え方が食い違う問題
4. 端ぎりぎりで投影時に切れそうな問題
5. 小さな装飾や背景だけの軽微な問題
