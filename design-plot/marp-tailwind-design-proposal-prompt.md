# Marp+Tailwind デザイン提案プロンプト

以下をそのまま生成AIに入力してください。

```text
あなたはプレゼン資料デザインの専門家です。以下の条件に厳密に従い、Marp + TailwindCSS向けのデザイン提案を作成してください。

# 目的
指定したカラーコードと参考イメージに基づき、統一感のある業務向けプレゼンデザインを提案する。

# 前提デザイン要件（厳守）
- トーン: 明るいグレー背景 + 濃紺見出しの静かな業務資料トーン
- アクセント: 青緑系を1スライド1〜2色まで
- 禁止: 赤・黄・オレンジなど派手色の常用（注意喚起時のみ限定使用）
- 余白: 広めに取り、情報過密を避ける
- スライド比率: 16:9（1280x720想定）
- 文字階層: タイトル / 本文 / 注釈 の3段以内

# 使用カラーコード
- 背景: #f3f4f6
- サーフェス: #f8fafc
- 見出し: #27456f
- 本文: #4b5563
- 補助: #6b7280
- アクセントNavy: #2f4f75
- アクセントTeal: #5fa0ab
- 補助アクセントGreen: #58c06b
- グラデーション: #2f4f75 -> #4ba8b4
- グレースケール: #f3f4f6 / #e5e7eb / #d1d5db / #9ca3af / #6b7280 / #4b5563 / #374151

# 参考イメージの解釈方針
- フラット系イラスト、UIモック、説明図を優先
- 背景は通常スライドでは無地、扉/区切りのみグラデや抽象波形を使用
- カードUIは角丸・薄い境界線・弱い影
- 視線誘導は「大見出し -> 要点カード -> 補足テキスト」

# 必須レイアウト提案（5種）
1. タイトルスライド（左寄せ大見出し + サブタイトル）
2. セクション扉（濃紺→ティールのグラデ背景）
3. 2カラム比較（Before/After または 期待/現実）
4. 3カラムカード（画像+テキスト or 指標比較）
5. まとめ/クロージング（要点整理 + 次アクション）

# コンポーネント規則
- 標準カード: rounded-xl + border(gray-200) + bg(gray-100) + shadow-sm + 十分なpadding
- 強調カード: navy-tealグラデ + 白文字
- ステップ要素: 同一サイズカードを等間隔で横並び
- 矢印や罫線: グレー単色で細く
- ページ番号: 右下固定、薄グレーで小さく

# 出力フォーマット
以下の見出し順で出力してください。

1) デザインコンセプト（3〜5行）
2) カラーパレット定義（役割付き）
3) タイポグラフィ設計（タイトル・本文・注釈）
4) スライドテンプレート仕様（上記5種それぞれ）
5) コンポーネント設計ルール（カード、比較表、ステップ、注釈）
6) Marp + Tailwind 実装ガイド（推奨class例を具体的に）
7) NG例と回避策（3つ）

# 制約
- 提案は実装可能な粒度にする
- 抽象論だけで終わらせず、class名・余白・文字サイズの目安を明記
- 全体の一貫性を最優先する
```

## 使い方
- 参考画像を一緒に入力する場合は、上記プロンプト末尾に「添付画像を優先参照」と追記してください。
- テーマを変えたい場合は「使用カラーコード」だけ差し替えて再利用できます。
