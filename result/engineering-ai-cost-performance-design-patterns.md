# Engineering AI Cost Performance デザイン要素抽出

## 抽出元
- PDF: `Engineering_AI_Cost_Performance.pdf`
- 解析対象: 15ページ（`result/pdf_pages/page_01.png` 〜 `result/pdf_pages/page_15.png`）
- 参照フォーマット: `elements/marp-tailwind-design-elements.md`

## 1. デザインコンセプト
- トーンは「エンジニア向け設計資料」: 設計図・寸法線・グリッドを使ったテクニカルな印象
- ベースは白背景 + 極細グリッド + 濃い本文色（黒寄り）
- 強調色はブルー単色系で統一し、赤は失敗例（A）など限定的に使用
- 1スライド1メッセージを大見出しで先に提示し、下段で図解・比較・手順に展開する構造

## 2. カラートークン（推奨）
```css
:root {
  --c-bg: #f8fafc;
  --c-grid: #d6dee8;
  --c-text: #111827;
  --c-muted: #4b5563;

  --c-primary: #0b56b3;
  --c-primary-dark: #1e3a8a;
  --c-primary-line: #2c5f93;
  --c-primary-soft: #e8f1fb;

  --c-border: #8aa8c6;
  --c-panel: #f3f4f6;
  --c-danger: #c23b3b;
}
```
- 強調は `--c-primary` と `--c-primary-dark` の2段階で十分
- 枠線・寸法線は `--c-border` / `--c-primary-line` の細線を使い分ける
- 背景に濃色ベタは使わず、常に高コントラストな可読性を維持

## 3. タイポグラフィ
- 見出し: `Noto Sans JP` 太字相当（日本語大見出し + 英語補助語）
- 本文: 中太〜標準、短文で改行して情報塊を分離
- 英語キーワード（Prep/Gen/Rework, QA Checklist など）を見出し語として併記
- 数式・変数・番号（01/02/03, 1/2/3）を視線誘導の主役に置く

- ヒーロータイトル + 中央メイン図（p01）
- 問題可視化: 大イラスト + 比較パネル（A/B）2分割（p02）

## 5. コンポーネント仕様
- 設計図フレーム: `border border-[var(--c-border)]` + コーナー装飾線
- パネル: `rounded-lg border bg-white/90`（影は極小）
- 比較カード: 左右で背景濃度を変え、強調側のみ太枠ブルー
- 番号バッジ: 大型数字を青ベタで配置し、行頭アンカーに使う
- フェーズ図形: 矢印/六角/円環を線画ベースで統一
- コールアウト: 短い矢印線 + 太字ラベル（長文注釈は避ける）

## 6. 背景・ビジュアル
- 全体背景は薄いグリッド（方眼紙）
- 図形は「寸法線つきテクニカルドローイング」風に統一
- 写実写真は最小限（端末画面モック程度）
- アイコンは線画または単色フラットでトーンを揃える

## 7. Marp + Tailwind 実装ガイド
- 16:9（`1366x768`〜`1376x768`想定）
- 余白は大きめ（左右70px以上、上80px以上）
- 推奨ユーティリティ例:
  - 背景グリッド: `bg-[linear-gradient(...)]` をCSS変数化
  - 見出し: `text-6xl font-extrabold tracking-tight text-[var(--c-text)]`
  - 図解線: `border-[1.5px] border-[var(--c-primary-line)]`
  - 強調語: `text-[var(--c-primary)] font-bold`
- 崩れ対策:
  - 3カラムは `grid-cols-3 gap-8` を固定
  - 大番号カードは `min-h-*` で高さを揃える
  - 長文は2行以内に要約し、詳細は別スライド化

## 8. 最小テンプレートセット（先に作るべき5種）
1. ヒーロータイトル + メイン図
2. 数式 + 3カード分解
3. A/B比較テーブル
4. フェーズ連結ステップ（3〜4段）
5. クロージング（3指標 + 結論文）

## 9. デザインルール要約
- 白 + 方眼 + 青線画で世界観を固定する
- 強調は「色数を増やさず、太さ・サイズ・番号」で作る
- 英語キーワードはラベル用途、日本語で意思決定文を書く
- 1枚に詰め込みすぎず、図1つ + メッセージ1つを徹底する
