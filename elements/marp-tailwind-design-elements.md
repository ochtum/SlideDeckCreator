# Marp+TailwindCSS デザイン要素抽出

## 抽出元
- URL: https://qiita.com/hirokidaichi/items/243bd176b84900f4cc0d
- ローカル画像: `image/` 配下 17ファイル（レイアウト一覧、配色ガイド、サンプルスライド、UIキャプチャ、背景・イラスト素材）

## 1. デザインコンセプト
- ベースは明るいグレー背景 + 濃紺見出しの「静かな業務資料トーン」
- 強調は青緑系アクセント（1スライド1〜2色）
- 派手色（赤・黄・オレンジ）は常用せず、状態表示や注意喚起に限定
- 余白を広く取り、情報密度を上げすぎない

## 2. カラートークン（推奨）
```css
:root {
  --c-bg: #f3f4f6;
  --c-surface: #f8fafc;
  --c-heading: #27456f;
  --c-body: #4b5563;
  --c-muted: #6b7280;

  --c-accent-navy: #2f4f75;
  --c-accent-teal: #5fa0ab;
  --c-accent-green: #58c06b;

  --c-gray-50: #f3f4f6;
  --c-gray-100: #e5e7eb;
  --c-gray-200: #d1d5db;
  --c-gray-400: #9ca3af;
  --c-gray-500: #6b7280;
  --c-gray-600: #4b5563;
  --c-gray-700: #374151;

  --c-grad-start: #2f4f75;
  --c-grad-end: #4ba8b4;
}
```
- セクション扉・クロージングは `navy -> teal` グラデーション
- 本文はグレースケール主体、アクセント色は最小限

## 3. タイポグラフィ
- 見出し: 太字・濃紺（例: `text-5xl font-bold text-[var(--c-heading)]`）
- 本文: 読みやすさ優先（例: `text-2xl leading-relaxed text-[var(--c-body)]`）
- 補助テキスト: `text-gray-500`〜`text-gray-600`
- 1スライドの階層は「タイトル / 本文 / 注釈」の3段までに抑える

## 4. レイアウトパターン（頻出）
- タイトルスライド（左寄せ大見出し + サブタイトル）
- 2カラム比較（Before/After, 期待/現実）
- 3カラムカード（画像+テキスト、指標比較）
- タイムライン/ステップ（横並び + 矢印）
- パネル型（薄い背景カード + 角丸 + 影弱め）
- 引用スライド（濃色背景 + 白文字）
- Q&A・中央メッセージ（中央寄せ最小要素）
- まとめ（ガラス風カードの並び）

## 5. コンポーネント仕様
- カード: `rounded-xl bg-gray-100 border border-gray-200 shadow-sm p-8`
- 強調カード: `bg-gradient-to-r from-[#2f4f75] to-[#4ba8b4] text-white`
- ステップボックス: 同サイズカードを等間隔に配置
- 図解矢印: 単色グレーで細め、情報競合を避ける
- ページ番号: 右下固定・小さめ・薄グレー

## 6. 背景・ビジュアル
- 基本は無地（`#f3f4f6`）
- 扉/区切りのみグラデ背景や抽象波形背景を使用
- 画像はフラット系イラスト（青緑トーン）を優先
- 実写よりも説明図・アイコン・UIモック中心

## 7. Marp + Tailwind 実装ガイド
- 16:9固定（1280x720想定）
- コンテナは左右80px以上、上下60px以上の余白を標準化
- Tailwindユーティリティをテンプレート化して再利用
- レイアウト崩れ対策:
  - カード高さを揃える（`min-h-*`）
  - 長文は行数制限または2段化
  - フォントサイズは `text-xl`〜`text-5xl` に限定

## 8. 最小テンプレートセット（先に作るべき5種）
1. タイトル
2. セクション扉
3. 2カラム比較
4. 3カラムカード
5. まとめ/クロージング

## 9. デザインルール要約
- 一貫性を最優先（色・余白・カード形状を固定）
- グレースケール土台 + 青緑アクセント
- 視線誘導は「大見出し -> 要点カード -> 補足」の順
- 1スライド1メッセージを徹底
